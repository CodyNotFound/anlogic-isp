# YuNet 离线训练工具

当前工作以 [部署合同](DEPLOYMENT.md) 为准：保持正式程序的完整网络层数和通道数，从官方预训练参数微调，不使用slim结构。训练尚未启动。

已验证的基础：

- Python输入参考与实际`yunet_rgb_snapshot`在完整1280×720帧上，61440个BGR0字节逐值一致。
- 原始预训练权重下，PyTorch与ONNX在160×96输入上的9个检测头对齐，最大绝对误差小于0.000001。
- `schedule.py`可从原量化参考重现正式program、四个weight bank、bias与shift的全部数值，包含当前DW tap优先布局。

待适配的训练环节：现有`data.py`使用直接低分辨率缩放，部分评测使用letterbox、NMS和旧匹配口径；不能不加修改就视为硬件等价。下一步应统一高清增强→整数块平均的输入流程，并用实际定点解码进行模型验收。已有`train.py`是基础工具，不代表已按新合同完成微调。

新权重需重新通过量化指数/LUT、18/20位累加范围、ROM打包、55层RTL逐值回归及整机编译；不会自动覆盖通过版。
