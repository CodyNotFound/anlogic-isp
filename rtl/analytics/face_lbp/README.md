# LBP 人脸位置检测原型

入口 `face_detector_snapshot.v`，完全由 Verilog 实现推理，Python 仅转换模型、准备图片和核对结果。
本页介绍底层独立快照核。当前主工程模式11已通过 `face_video_position` → `face_pose_snapshot` 集成视频、人脸位置及云台，最新算法与验证状态见 [v40验证说明](../../../doc/tracking_v40_validation.md)。早期可行性记录保留于 `doc/face_tracking_feasibility.md`、`reports/face_lbp/`。

## 用法与边界

- 单时钟；输入 **160×90、8-bit 灰度、逐行扫描**。不接 RAW10/Bayer。
- 等待 `ready=1`，给一拍 `frame_start=1` 且 `pixel_valid=0`，随后输入准确的 14,400 个有效像素。
  `pixel_valid` 可以有空隙，连续一拍一像素也支持。帧缺像素需要复位，不能用下一帧接着凑数。
- `model_select` 在 frame_start 锁定：0 真人正脸，1 动漫脸。照片中的脸也可检测；不判断是否活人。
- 扫描期间采用单帧积分图，不能并行写下一帧。上游应**整帧丢弃**忙期间的图像，不允许阻塞 HDMI。
- 只在 `result_valid=1` 采纳 `target_found/target_x/target_y/target_size/target_votes`。
  框坐标原点为左上角，右下角不含；center = 左上角 + floor(size/2)。无目标时框置零。
- `ready` 覆盖分类与候选筛选的占用；`busy` 仅反映核心捕获/扫描占用，不能用 `!busy` 代替 ready。
- `overflow=1` 表示超过 16 个独立候选组，强制 target_found=0。
- 此底层模块输出本帧票数最多的一组；视频/姿态包装层另做跨帧确认与跟踪。输出不是身份、概率、目标分割或活体判断。
- 此底层模块可独立综合、仿真；生产集成使用视频包装层，自动云台由SW3使能、SW4手动优先。下文独立探针不是生产板卡bit。

core 参数 WIDTH/HEIGHT 保留用于实验，但当前 ROM/测试/包装层固定160×90。
改变输入尺寸前必须重新检查：14-bit存储地址、22-bit积分值、8-bit坐标、最小64像素帧尺寸。

## 算法

1. 流式建立22-bit积分图，上一行同步读、本行流水写，行首和帧首显式处理。
2. 窗口边长24/28/32/40/48/64，每像素移动一次，遍历38,818个位置。
3. 读特征4×4角点，获得3×3方块和；周围8块分别与中间块比较，得到8-bit LBP。
4. 查256-bit类别掩码，累加左右叶分值，某一级失败立刻拒绝。
5. 真人20级139个弱分类器；动漫20级771个弱分类器；共享数据通路，参数ROM合并存储。
6. 叶/阈值为24-bit有符号Q22（数值范围[-2,2)），级内和32-bit；模型转换保留OpenCV阈值容差。
7. 16组候选按位置和大小合并，每组首个框作为代表，至少3票才发布；票数不是置信概率。v40将合并实现改为串行复用与同步存储，保持相同合并规则；队列或组数溢出都会拒绝整个快照。

特征几何随窗口缩放，非OpenCV的图像金字塔；量化和合并规则也单独测试，不能用CPU库准确率代替本核准确率。
真人与动漫采用人工选模式；若每帧串行跑两种，需要分别捕获/保留同帧及调度，延迟会增加。

## 复现

在 PowerShell 的项目根目录运行：

```powershell
./scripts/run_face_lbp_sim.ps1
./scripts/build_face_lbp_probe.ps1 -RunName face_lbp_probe_new -Implement
```

ModelSim默认路径在脚本中，可传ModelSimBin；Python依赖numpy、Pillow。所有训练参数和测试原图已存本地，仿真不需要网络。
探针使用同一PH1P35MDG324/-3、13.468ns内部时钟约束，随机IO脚位仅用于独立资源/时序试验。
**探针不是开发板工程，不可把探针文件下载到板上。**

脚本看到FAIL/Fatal、缺少PASS或工具非零退出都会报错；modelsim个别Fatal可能返回零，不能只看退出码。
数据来源及署名见 `sim/face_lbp/SOURCES.md`。ROM相对路径以仿真工作目录为基准；独立TD探针显式传绝对路径。

生产姿态包装层使用九个尺度（另含72/80/88）与歪头视图补偿。已有目标优先局部复核，局部分类失败且有可靠梯度模板时最多续跟两次，否则完整搜索。旋转补偿针对平面歪头，不能当作多姿态模型或可靠侧脸检测；它也不识别人的身份。
