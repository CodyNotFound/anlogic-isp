# 云台 v38 提速验证（2026-10-21）

用户反馈手动和自动都过慢。本次仅修改servo_gimbal_ctrl，不改图像算法、开关、按键分工和安全脉宽边界。AWB常开，SW1=AB、SW2=AE、SW3=AUTO、SW4=MAN。

## 速度策略

- 短按4µs/20ms微调；相同方向持续约200ms后32µs/20ms快速移动。松手停止，退出手动、松开或换方向恢复细调；反向键同时按仍抵消。
- 自动保持位置死区：水平±8、竖直±6分析像素。死区外步进为ceil((绝对偏差−死区)/2)，限制1～32µs。每条新结果最多积分一次，持续valid不重复使用。
- 水平500～2500µs、竖直1050～2150µs；PWM仍为50Hz原子更新。SW3关闭保持，SW4手动优先，丢失保持/回中策略不变。
- 快速段按270°/2000µs标称比例为216°/秒的指令速率；不代表实测机械到位速度。

## 新旧RTL同条件比较

基线从保留的v37发布源复制并仅改模块名。下面测量同样500µs的指令行程；自动为固定大偏差输入，用于隔离控制器响应，不是摄像头闭环到位时间。

| 条件 | v37 | v38 |
| --- | --- | --- |
| 手动长按1500→2000µs | 2.50s | 0.50s |
| 自动10次位置结果/秒，1500→1000µs | 12.42s | 1.52s |
| 自动30次位置结果/秒 | 4.14s | 0.50s |
| 自动50次位置结果/秒 | 2.50s | 0.32s |

记录的是首次达到或跨过500µs行程阈值；离散步进可能跨过阈值。数据为reports/gimbal/v38_final/speed_measurements.csv；run_gimbal_speed_sim.ps1可复跑。另在160×90生产尺寸运行真实取样/移动分析：模板匹配297673周期（75MHz下3.969ms），色区470007周期（6.267ms）。这是该合成场景的计算延时，排除了采图、帧边界等待和结果路由；不能当作实物识别帧率。

## 回归

- 新控制器检查：PWM周期/脉宽，快速与细调、换向复位、自动大偏差32µs/19µs、中心附近1µs、死区零步进、持续valid不重复积分、限位与丢失处理。
- 75MHz实参数PWM、数码管、五模式OSD，实际开关/按键到控制器，以及原生K4色区采样→质心→PWM均重新通过。
- 图像分析器及像素链没有修改，复用已归档v37的原生分析、FACE/直通、实际字库合成、AB、既有模式回归；独立的人脸接线测试不充当识别准确率证据。蜂鸣器源和用例未变。
- 生产尺寸延时测试有16项未连接输出端口告警，这些输出不参与延时测量；无Error/Fatal。测试日志及哈希以发布包completion.json为准。
