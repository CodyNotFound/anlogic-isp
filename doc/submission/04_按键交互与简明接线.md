# 安芯智视操作与连接说明

系统通过板载四个按键、四个功能拨码和 HDMI 中文提示即可完成基本操作，无需串口屏。串口屏是可选的图形化控制入口，适合把模式选择与状态查看集中到触摸页面。

## 一 接线只看五组

| 连接 | 操作 |
| --- | --- |
| 摄像头 | 将 SC500CS 接至开发板配套摄像头接口 |
| 显示器 | HDMI 连接开发板和显示器 |
| 水平舵机信号 | J1-1 → 水平舵机信号线 |
| 俯仰舵机信号 | J1-2 → 俯仰舵机信号线 |
| 电源与公共地 | 两只舵机由独立 6 V 电源供电，电源负极与开发板 J1-12 共地 |

两路 PWM 和一根公共地构成云台的板端连接。舵机电源直接来自独立电源，不从开发板 5 V 或 3.3 V 引脚取电。断电接线，按板上 J1 引脚标记确定方向。

【插图：俯视实物连接照，用五种标注指出摄像头、HDMI、水平信号、俯仰信号和电源共地；无需放完整开发板原理图。】

## 二 四个拨码各管一件事

| 拨码 | 开启 | 关闭 |
| --- | --- | --- |
| SW1 白平衡 | 自动更新颜色增益 | 锁定当前颜色增益 |
| SW2 曝光 | 自动调整曝光 | 锁定当前曝光状态 |
| SW3 跟随 | 允许有效目标驱动云台 | 停止自动运动，仍显示检测结果 |
| SW4 方向键 | 四键用于左下上右 | 四键用于模式切换和目标选取 |

锁定白平衡或曝光前，先等待画面稳定。锁定会保留当前参数，适合同场景比较效果。SW4 只切换按键用途，真正的自动运动开关是 SW3。

## 三 四键有两套清晰用途

| 按键 | SW4 关闭 | SW4 开启 |
| --- | --- | --- |
| K4 | 模板/色区取样；运动模式重建参考 | 左 |
| K3 | 普通模式下无须操作 | 下 |
| K2 | 上一个模式 | 上 |
| K1 | 下一个模式 | 右 |

模式连续循环：00 色彩还原、01 灰度、02 反色、03 二值、04 增亮、05 锐化、06 模糊、07 边缘、08 浮雕、09 卡通、10 换色、11 人脸、12 模板、13 色区、14 运动。

方向键短按微调，长按持续移动。自动跟随中按住方向键可临时接管；松开后，系统等待新的有效定位结果再恢复自动，不沿用旧目标继续累加动作。要完全固定机位，关闭 SW3 并松开方向键。

【插图：按实物从左到右排 K4、K3、K2、K1，上排写“取样、—、上一项、下一项”，下排写“←、↓、↑、→”；旁边用 SW4 图标说明切换关系。】

## 四 三十秒上手

1. 开启 SW1、SW2，让颜色和曝光稳定；按需要锁定。
2. 关闭 SW3、SW4，用 K1/K2 选择模式。
3. 人脸模式等待自动定位；模板或色区模式将目标置于中心标记，按 K4 选取。
4. 看到有效目标后开启 SW3，观察云台跟随。
5. 要调整方向，开启 SW4 并按方向键；要继续切模式，关闭 SW4。

运动模式采用固定机位：关闭自动跟随，等待云台停稳，按 K4 建立参考，再让物体进入画面。

## 五 中文界面帮助确认每一步

模式名回答“现在运行什么”；目标状态回答“是否找到、是否搜索”；坐标和框线回答“检测到哪里”；H/V 显示 PWM 指令位置；开关状态提示白平衡、曝光和自动跟随是否启用。界面上的毫秒值按模式分别表示普通应用链帧首计数或视觉任务计算耗时。

## 六 可选串口屏

通过兼容的 UART 串口屏，可把模式选择、自动/锁定切换、目标重选和方向控制做成触摸按钮，并集中显示运行状态。它不参与视觉推理；不接屏时，板载交互仍可完成基本操作。

屏幕明确操作可取得控制权；实体按键按下或实体开关变化可接回本地。周期查询不会反复抢回控制权。方向按钮按住时持续发送，松开时发送停止；超过 250 ms 未续发方向指令会停止远端方向运动。

串口屏接入前按所选屏幕核对供电和 UART 电平，RX/TX 交叉连接并共地；本说明不指定尚未确认的屏幕型号或引脚。拍摄主片可先完整展示板载操作，屏幕调通后再补一段“触摸切换—画面响应—实体接管”。
