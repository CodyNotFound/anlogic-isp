# v62 fixed-camera motion detection

New production mode15 MOVE, after mode14; old mode13 remains skipped. K4 resets reference in mode15. Existing modes, Logo, panels and control labels retain their definitions. Motion adds status only in its own mode: building reference, no motion, motion detected, light change, camera moving; existing target XY/PROC row is reused. Mode15 never enables automatic servo motion. Manual control retains priority.

Data path: existing8x8 RGB-average sampler ->160x90 luma -> compare previous frame in idle CNN RAM -> write current luma back. Previous-frame byte range0..14399. Motion, FACE, TRACK and REGION are mode-exclusive; no new frame BRAM. A one-bit row support mask uses distributed storage. Absolute difference>=12, adjacent-change support, minimum8 changed samples/6 supported samples, bbox density>=1/16 and two consecutive nearby candidates precede publication. Changes affecting>3/8 frame are rejected as global illumination. This is a bounded frame-difference demonstration, not semantic or individual-object tracking; large/low-density motion, subtle or very slow changes and hard noise can be missed.

Manual mode or changed PWM commands suppress motion and invalidate reference; wait15 input frames after the last command before rebuilding. This observes commands, not physical position feedback; mechanical settling must be verified on board. First complete frame initializes. Malformed/partial input invalidates reference and releases host writes. Serialized RAM work completes within five clocks between samples (at least eight clocks apart). Work counter is sized from N*4+2, zero-extended for existing telemetry.

Tests: actual CNN RAM tests W16x12 and W160x90; exact slow-motion bbox, stationary rejection, illumination change, isolated pixels, suppression, abort and mode ownership. Fresh native128x96 RGB suite tested98304pixels with actual8x8 sampler and CNN RAM, no injected motion decisions. Native qualifiers preserved. Narrow work counter repeated production regression passed. No live-camera acceptance claimed.
