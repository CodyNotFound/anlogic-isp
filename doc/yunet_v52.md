# v52 人脸定位整板候选

本轮不是肤色规则调参：FACE 11 使用预训练 YuNet 的完整位置分支，摄像头 RGB 经 8×8 均值采样得到 160×90，补零至 160×96 后由 FPGA 执行 55 个整数算子。仅删除没有使用的关键点分支，模型参数与 v49 功能基线一致。

## 本轮修改

v50 的整板综合为 109/108 RAM。v51 将两张色区掩膜改成分布式存储后，RAM 为 107，但实际布局报告 M-Slice 9960/8112，不能使用。v52 从 v50 分支重新开始，保留两张掩膜的块 RAM，只将 CNN 四个行缓存银行中的第零个改为分布式映射。

缓存读地址增加一级寄存器，利用已有 READ / WAIT / FEED 三拍完成寻址、读数、使用，不增加算子周期。这是实际流水线修改，必须重新运行完整网络逐字节比对及原生 RGB 到 PWM 仿真，不能仅继承旧日志宣称通过。

`scripts/on_td_complete.ps1` 增加 M-Slice 8112 的独立容量检查；仍须同时通过最终总 slices、108 RAM、40 DSP、setup/hold、源码哈希及 bit 校验。独立 CNN 路由成功不代表整板成功。
