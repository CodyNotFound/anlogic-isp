# v45 YuNet 人脸定位硬件落地

本分支是真实CNN推理实现，替换目标是旧LBP检测器。主目录v43和独立v44降噪代码保留；本分支顶层显式选择FACE_CNN_ENABLE=1进行整板资源检查。尚未烧录。

## 已实现

官方MIT许可YuNet 2023mar原始模型、SHA256和许可证保留在models/yunet。只剪除无需使用的五点关键点分支，保留三种尺度的分类、目标性和边框回归。输入为160×90 BGR图像加六行零，逐层int8特征/权重、int32偏置和累加、按输出通道二进制移位。原始摄像头输入0..255，未误当成有符号int8。

完整网络47个卷积层，降低后55个操作，49,330个有效权重字节，12,678,450次原始MAC。首层按四通道补零，以使用四银行RAM，实际ROM含对齐填充。网络调度、银行存储、同步读延迟、卷积/深度卷积/池化/最近邻放大/相加均有RTL实现，没有用电脑输出坐标替代检测。

yunet_dot4共享四个DSP；yunet_network执行完整网络；yunet_decode用Q7 sigmoid、Q4几何LUT和三尺度最高分目标选择，输出现有720p方框及中心接口。该策略目前没有历史目标关联，也不做身份识别。yunet_position_snapshot串联整网和解码；yunet_rgb_snapshot完成真实RGB均值缩采样、BGR0写入、补零、采集中断拒绝和忙时跳帧；face_video_cnn连接摄像头与位置有效期，旧云台丢失保持策略不变。

## 已有证据及边界

- Python浮点降图与ONNX Runtime逐步比较55个节点，最大绝对误差8.5831e-6。
- 四路RTL点积：4,602个真实网络/边界样例，38,736个输入拍，覆盖全部47个卷积层的每个输出通道、图像角落、符号、舍入、饱和、停顿和复位；PASS。
- 完整网络RTL：一张真实图片，55步共659,460个中间特征字节，全部逐值一致；19,490,300拍。按75MHz计算约259.9ms，仅是核心计算，不能称为60fps人脸检测。
- 整数解码RTL：17个开发图像的完整三尺度输出流，全部通过。它验证解码规则，不构成独立人脸准确率评测。
- RGB采样RTL：640×360输入逐值核对61,440个BGR0字节，包含完整补零、异常行结束和忙时跳帧；PASS。
- 真实RGB输入→整网→坐标三项完整仿真已启动：正脸、近距离-30度歪头、非人脸水果。结果以reports/yunet_v45/position_*.log为准，未结束前不记为通过。

当前17张开发探针用于同组校准及回归：近距离裁剪及±15/±30度均检出，部分缩小歪头样例在原浮点模型中也漏检；messi小脸和手办也未检出。不能据此承诺泛化准确率、真实距离范围或手办支持。照片旋转只用于离线测试，硬件没有旋转重试。

## 物理实现仍需解决的问题

四路点积独立75MHz布线：537 slices、4 DSP、0 RAM，setup +0.105ns、hold +0.069ns。

完整网络基线独立布局：3,118 slices、84 RAM、4 DSP；路由完成但setup -4.500ns，hold +0.134ns。旧probe_job的status只表示工具流程结束，不能作为时序通过依据，以实际phy.ts为准。主要长路径是通用地址计算，下一轮应流水化/约束到实际支持尺寸。共享乘法器本身通过不代表整个网络满足75MHz。

本基线缓存完整特征图，arena为128KiB，高水位122,880字节，不能把独立模块的84 RAM直接累加进主工程。整板候选正在编译，必须以替换旧检测器后的实际资源报告判断；下一轮重点是缓存复用和首段流式融合，不降低标准来宣称当前已可上板。

## 重现

安装models/yunet/requirements.txt，运行scripts/yunet_integer.py、yunet_dot_vectors.py、yunet_decode_vectors.py和yunet_schedule.py。scripts/run_yunet_sim.ps1运行完整图片到坐标的RTL仿真。scripts/build_yunet_probe.ps1支持dot和network独立硬件探针；scripts/run_td_verified.ps1负责整板Check、综合、布线及源码哈希门禁。所有模型/参考和仿真结果位于reports/yunet_v45。
