# v49 模板与CNN复用帧缓存

模板模式12与人脸模式11互斥，模板帧改为借用CNN的64KiB特征区，按字节线性访问。区域模式14暂未共享。CNN计算控制在模板模式复位，但该RAM的读写进程不受复位清空；不能把存储读写也加上复位门禁，否则会破坏模板模式。

模式切换先重置分析状态，再等待完整新帧。模板重新捕获14,400个灰度字节，人脸重新捕获61,440个BGR0字节后才启动网络；两种内容不混用。摄像头流不等待计算。

原vision_sad_tracker与vision_task_suite默认仍使用本地帧存储，新增共享端口显式接入；位置/质量/SAD/丢失策略没有更改。
