# v48 相加/量化时序收敛

v47的39处原地复用已通过完整55步和三组实际图片到坐标回归；独立RAM为60块，但75MHz路由setup -3.471ns。关键路径为BRAM读出、输入尺度对齐、64位求和/舍入/饱和，不能因为模型算术正确而忽略时序。
