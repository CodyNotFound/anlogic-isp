# v70 原生点阵 OSD 预览

用户指出v69顶部英文数字仍过大，中文粗细不均。原因：16px中文逐点映射到24px时，行列交替重复1/2次，会改变笔画厚度。v70删除F_grid24/F_ascii_row24，不再对任何字形像素做非整数重采样。

字体ROM完全不改。中文为原生16×16 ZLabs；英文数字为v66原来的粗点阵，12或16像素字符推进只影响字符间距，读取的字体列/行仍逐像素1:1。统一16px字符画布，保留字形自然的大小写高度与标点，不把标点拉满字高。

左上Logo与文字仍统一半透明底色，面板从504×110收窄为388×110；原Logo146×94保持。模式/状态同一行(188,48)/(316,48)，坐标下一行(188,80)。右上192×52面板，FPS和PROC均原生小尺寸，ASCII推进12px。底栏缩至400×40，仍保留四项状态及按键说明。云台160×144不再扩大，位置下移28px给底栏留16px间距。

仿真已验证三帧720p、2764800已知RGB像素、40处独立文字、统一Logo背景和原调色板。中英文字模与v67/v66原数据逐值一致；图像与云台控制算法、引脚、UART协议均未改。此为已验证RTL预览，并未启动本版本整机综合或生成新bit；v69正在独立工作树完成原有编译，不修改其输入或删除证据。
