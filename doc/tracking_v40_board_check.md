# v40 上板检查记录

先确认烧录文件对应发布目录及SHA256。本文不代表已做实拍验收。

## 操作入口

- SW4关：K1/K2切模式；在人脸模式自动检测，模板/色区模式用K4在画面中央取样。
- SW4开：手动云台优先，K4/K3/K2/K1对应左/下/上/右；此时K4不会取模板或颜色。
- SW3开：允许由当前人脸/模板/色区的有效位置自动控制云台；SW4手动仍优先。
- 首先SW3关、SW4关，检查框和位置，再开SW3验证云台，避免把误检与控制方向问题混为一谈。
- AWB常开，SW1为AB、SW2为AE；本轮不改这些映射。

## 人脸

保持整张脸在画面内，依次检查正脸、靠近、左右歪头、缓慢横移、短暂遮挡、完全离开、重新进入。第一次捕获需要两次位置及尺度一致的真实级联结果；首次歪头搜索仍可能明显慢于已经锁定后的移动。

确认稳定后不应每隔八个结果出现一次完整搜索停顿。级联漏检时梯度模板最多维持两个结果，不能无限跟住遮挡物。完全丢失后重新检测，允许重新捕获进入画面的人脸。

当前角度补偿针对平面歪头；大侧脸、低头仰头、脸被画幅截断不在已验证能力内。固定照片仿真不能保证真实灯光、肤色、眼镜、运动模糊下的准确率。

## 模板

让目标主要纹理落在中央128×128源像素窗口，SW4关时按K4。依次做小幅平移、左右倾斜、小幅远近变化、短暂遮挡。窗口包含背景时，背景也会进入模板，应记录是否因此误跟。

允许的模板为0、±6、±12、±18度及两个单独尺度候选，不覆盖任意角度与尺度的联合变化。丢失时最多额外三次局部尝试，超出后按K4重新选；不会全图寻找任意相似物。框表示采样窗口，不能当作物体真实轮廓。

## 色区

用纯色区域覆盖中央取样点，SW4关时按K4，观察校准及区域状态。首次目标应经过取样位置；然后缓慢移动，同时在画面远处放一个更大的相近颜色区域或灯，检查是否仍保持原目标。

先移走目标，确认不会切到远处大区域，再放回原位置附近；需要选其他区域时按K4清除关联。两个相近候选、混色取样或过亮区域可能被拒绝，这是防误锁的一部分。同色相邻物或与背景连成一片仍可能分不开。

## 记录

分别记录每个模式的首次捕获时间、移动时框是否跟得上、误锁对象、遮挡后是否停止、重新捕获时间，以及SW3开关后的舵机表现。每次只变一项（距离/歪头/灯光/遮挡），保留版本、开关状态及短视频，便于定位问题。

舵机接线及供电仍按gimbal_wiring_hx1p35a.md；竖直软件范围1050～2150µs，禁止越过碰撞位置。
