# 片上颜色处理 v1（2026-10-14）

适用入口：`td_project/camera_to_dsi_display.al`，顶层 `design_top_wrapper`，PH1P35MDG324，1280×720 RAW10 BGGR，4像素/拍。相位依据本批摆件实物确认，不能沿用早期 GRBG 测试结果。

## 原版与本版

| 环节 | 原版 | 本版 |
| --- | --- | --- |
| 黑电平 | BLC ENABLE=0 | RAW域先减67，负数夹零；未知模拟增益下仍为暂定值 |
| 空间校正 | 无 | 去马赛克前17×13×4节点Q2.10表，80×60网格双线性插值 |
| 主白平衡 | 原ISP扫描AWB | 中性色门限统计、逐帧全局R/B增益；初值522/256、421/256 |
| 显示端处理 | 可叠加AWB、HE和亮度 | 默认屏蔽后三个功能，只有SW1保留AE控制 |
| 曝光 | 传感器AE与数字增益修正 | 保留传感器AE；显示端数字增益上下限均256 |
| 颜色/显示 | 原线性RGB路径 | 横向边缘去紫、低色差保护的2.398倍饱和度、固定sRGB编码 |

流程：RAW10 → BLC+LSC → 原BGGR去马赛克 → 逐帧AWB → 横向去紫/饱和度/sRGB → 原96转128打包 → DDR/显示。

空间表是已采集室内灯、太阳光辅助两组归一化白场表的几何均值，重采样到硬件节点，**不会对当前画面重新拟合**。不是按绝对色温插值的多光源LSC，不能保证任何光源下完全无残差。全局AWB也不能改变左中右相对颜色。黑电平、饱和度、曝光目标仍需板上确认。

LSC：BGGR偶数行B/G0、奇数行G1/R；纵向、横向分别Q0.8取整插值，最后RAW×Q2.10四舍五入夹到1023。4个使能时钟延迟。

AWB：输入G≥12，RGB均<240，当前增益后的R/B均<240且介于0.75G与1.25G才统计；至少4096像素。共享40拍串行除法分别算R/B，增益限制128..768，1/8平滑且每次最大±8 Q8。候选不足保持旧值。结果只在后续SOF生效，启动和改变光源需等待多帧；没有中性色时可能无法收敛到正确白点。2个使能时钟延迟。

去紫：min(R,B)>G+8且与左邻亮度差>16时把G补一半；行首/帧首不跨边界。可能影响真实紫色物体的边缘，只是轻量抑制。饱和度在色差<8或Y<12时为1，其他为614/256。4个使能时钟延迟。固定sRGB映射不同于离线Python每图百分位曝光和二维去紫，因此不声称逐像素等价或绝对色准。

传感器AE目标改为编码后亮度128..160；数字增益固定1。这个区间是初始显示策略，并非从色卡标定得到。曝光只能改整体亮度，不能用来消除空间偏色。

## 流水和回退

新增模块的ready停顿冻结整个数据与sideband流水。既有96→128打包器不支持任意停顿或行内空洞，平台仍要求有效行连续、下游持续ready；此项不能当成完整AXI弹性流水。外部SOF使用RAW帧开始提前预告，EOL按每行240个输出字重建。

`isp_top`编译参数 ENABLE_LSC/ENABLE_AWB/ENABLE_COLOR 可分别旁路，旁路LSC也会旁路BLC。回退原版应使用安装时保存的五个原文件；仅旁路新增模块不等于原版。外部端口和引脚不变，未修改约束。

## 复现与验证

`python scripts/export_colorshading.py` 生成两张数据表和profile；需要numpy。`python scripts/check_flatfields.py <白场npy...> --out <json>` 检验定点空间表，需完整720×1280 uint16 RAW10。

ModelSim单元仿真：LSC完整230400拍、5792个停顿；AWB 616周期25拍；颜色327周期，均PASS。测试覆盖数学模型、元数据和停顿，未覆盖完整传感器到显示系统。`doc/compile/flatfield_metrics.json` 是参与标定的旧白场回放，不能算独立新白墙验收。

TD检查命令（PowerShell 7）：`pwsh -File td_project/build_colorshading.ps1 -Stage Check`。之后可同一RunName执行Synthesis、Implementation，旧目录里的bit不会自动更新。最终资源、布线时序和实际白墙必须分别确认，本文不代表已上板。

白墙验收：确认使用本次新构建bit；关闭OSD/图像效果并保持全视场；同一光源下待AWB稳定后抓完整RAW与显示图；观察左中右R/G、B/G是否残留。若仅整体偏色检查AWB；若仍有固定空间残差，检查表是否生效、Bayer坐标/镜像是否一致、黑电平与模拟增益是否改变，以及该光源是否需要单独LSC。不要通过裁图或给墙局部涂色拟合掩盖问题。

## legacy video_in 帧复位预告契约（2026-10-14 修正）

内部LSC/demosaic/AWB/color的user仍与各自首像素对齐。外部isp_top.O_tuser是native帧复位预告，等于I_tvalid && I_tuser；video_in收到后会展宽8个相机周期，经3级DDR同步复位FIFO，FIFO还有2级写域同步释放。外部SOF不能与首个128bit输出同拍，否则已写帧首数据被清除且复位期间数据丢失。

O_tready由vendor_lab1_core恒定驱动1。output_word_count在RAW SOF预告时优先清零，只按O_tvalid递增，在239回零；O_tlast仅O_tvalid && output_word_count==239。每行1280 RGB888像素对应240个128bit字。需验证SOF提前量、前帧尾不跨下一SOF，不能把AXI首字user语义套到此native边界。


## v9 验收契约（2026-10-14）
恢复四个低有效开关：SW1 AE，SW2 主ISP AWB，SW3 HE，SW4 AB。旧显示AWB固定旁路，避免双重白平衡。SW2两级跨域同步，接受内部首像素SOF时锁定整帧选择，SOF首beat即生效；两级数据/选择流水与原AWB同延迟，关闭时统计仍更新。ENABLE=0恒旁路，不新增DSP。开关去抖沿用原显示控制器；主AWB帧锁存避免帧内色阶切换。
Bayer矩阵保留1280x720全视场，镜像101补齐颜色相位：顶行邻居取row1，底行邻居取row718，左邻居取x1，右邻居取x1278。首RAW行只填行缓存；下一行才输出首行；末行后合成一行读出底行。矩阵六字节位于[71:24]，依次左、当前四像素、右。每帧720行，每行320个四像素beat。外部native提前SOF保持v8契约。
验收：实际RAM模型已补齐未连接写端web=0，禁止以全零数据宣称颜色验证通过。恒定BGGR场R240/G400/B160应在全部边界得到RGB8(60,100,40)，先发warmup帧让zhenghe学习行周期，再验证第二帧；另做空间变化场验证未移位/丢行。AWB开关数值、SOF、stall和ENABLE=0单元验证必须PASS；全720行两帧链路计数必须PASS；综合资源<=40DSP；最终路由setup/hold均非负。偏黄需同场景AWB开关对照，尚无新中性场RAW，不凭观感改变标定系数。

## v10 未编译源码修复：DDR 返回额度与 AWB 冻结
本节替代 v9 的运行时 AWB 关闭语义：关闭仅冻结自动估计并保持当前应用增益，所有像素继续共用同一条两级 AWB 流水。重新开启不得应用关闭前未提交的旧估计。
video_out 需按 FIFO 已存字数加未返回读请求计算预留容量；换帧必须丢弃并排空旧返回，再复位、同步释放、切换到新基地址。发生读空时不得继续用错位字节组成彩色像素；该帧剩余部分置黑并在下帧恢复。底行补齐保持测得的正常行周期。
