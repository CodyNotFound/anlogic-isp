# v43 紧凑OSD与SW3显示开关

本轮仅修改显示和控制分工，保留v42图像算法、颜色/模板/人脸模型及舵机速度。暗部灰化与噪声问题未在本轮修复，人脸CNN替换未在本轮实施。

## 操作

- SW1：AB；SW2：AE；SW3：OSD信息；SW4：手动优先。拨下有效，AWB常开。
- SW3关闭：只保留安路Logo，隐藏FPS、模式/状态、目标框、取样标记、云台位置和按键提示；后台分析和自动跟随继续。
- FACE11、TRACK12、REGION14自动使用有效位置，不再需要拨码开启。目标丢失、无新结果或退出跟踪模式时保持PWM，不自动回中。
- SW4打开时K4/K3/K2/K1为h/j/k/l（左/下/上/右），按原手动速度和限幅工作。需要暂停自动运动时打开SW4并松开方向键，或退出跟踪模式。
- K4取样/重选与K1/K2切模式沿用；SW3关闭时K4依然能取样，建议取样时开启显示以看清中央取样标记和结果。
- LED3对应OSD开关，不代表跟踪是否有效。数码管仍显示PWM指令，接线和供电不变。

## 布局与复用

- Logo保持原始146×94像素、坐标(24,24)、索引/调色板和透明像素，不裁小、不删除；SW3不能隐藏Logo。
- FPS移到右上(1204,26)，显示测得帧率，不写死60；模式与状态移到Logo右侧。
- 底部仅右侧384×36像素信息区，坐标(880,676)，物理SW4..SW1与K4..K1两行对齐；不再铺整条黑底。
- 云台96×100面板在(1168,568)，显示64×64指令位置图与H/V脉宽。该图不是编码器反馈。
- 所有信息底板只在hdmi_mixer中混合一次：RGB各通道右移1，即50%黑色；Logo透明处保留原视频。
- 生产任务HUD关闭自己的字形、BCD文字和背景，仅保留框/十字；文字、模式、FPS、状态、开关和脉宽统一复用现有font ROM与混合流水。原gimbal_osd实例保留两拍视频延迟，ENABLE=0，绘图网络由综合裁除。
- SW3先去抖，再在源帧首提交；各延迟覆盖层在自己的SOF锁存使能，避免跨帧流水尾部被提前隐藏。检测和自动控制不依赖SW3。
- 保留旧hdmi_mixer接口与默认兼容布局；生产工程显式设置COMPACT_OSD=1。

## 验证边界

scripts/osd_v43_reference.py独立使用原MIF字形与Logo，生成六张720p精确像素参考。sim/tb_osd_v43.sv检查完整应用RGB/时序、三类目标覆盖层、SW3帧中改变、Logo-only输出、手动提示以及隐藏显示后继续消费人脸位置驱动舵机。该用例在人脸/目标模块接口注入位置，只证明显示与控制，不证明识别准确率。

实际颜色采样/K4/质心到PWM、模式按键、独立任务集、PWM硬限幅及旧模式另做回归。构建和检查结果最终记录于reports/osd_v43/validation.json；未获得物理时序和功能PASS之前不作为可下载交付。

本轮第一轮Check发现活动.al缺少已有pixel_cartoon源条目；补回后另建r2，保留失败日志。不使用旧网表续编译。

本轮不烧录；面板观感、摄像头和机械动作仍需用户上板验收。
