# v46 地址时序优化

从v45完整CNN检查点741e68a开始，在独立工作树继续。v45保持冻结，整板综合和三组完整图片到坐标测试继续运行。

v45完整网络独立路由setup -4.500ns，主要长路径为stride2到通用行地址乘加再到RAM地址。生成的160×96网络只包含160/80/40/20/10/5六种行宽，因此用每种行宽两个固定移位项代替八项串行移位加法。运算结果对所有实际程序地址保持不变，不增加DSP，也不变更网络权重、量化或检测阈值。

这一轮只修地址时序，完整缓存仍为128KiB。缓存复用需要另做状态机与逐层回归，不能把本轮称为资源已满足整板。物理报告及55步精确特征回归完成之前均为候选。
