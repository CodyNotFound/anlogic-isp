# v71 外部输入控制与 OSD 收边

串口屏连接状态与云台手动状态分离；SW4不再强制覆盖屏幕退出请求，也不阻断SW3自动追踪；有效命令/心跳建立1秒连接租约，断线恢复本地功能开关，方向租约仍为250ms。回传增加vN连接位，vM仍最后提交。屏幕侧需按tjc_hmi_v71.md同步，尚未实物验证。

左上角增加串口屏已接入原生中文字模；Logo透明底色，模式/状态与坐标底板紧贴内容；右上角移除PROC，仅4位动态毫秒数与ms、FPS右对齐；右下角增加8像素内边距和1像素边框。字号、字形像素保持。

字体ROM仍为2048×16位、128字模。移除生产HUD未使用的J/K/L/Q/U/Z拉丁字母槽位，替换为6个原生ZLabs中文像素字模。原有可见ASCII与中文逐位不变，无分数缩放。该裁剪只适用于当前COMPACT_OSD生产HUD，历史英文诊断布局不再保证全字母覆盖。

OSD实RTL仿真：三帧720p、2764800有效像素、42处完整字形矩形、Logo透明/不透明像素、连接标记显隐、边距与边框均通过。完整UART到应用控制及PWM波形测试另见reports/hmi_v71，最终时序/资源与bit需以本版完整编译报告为准。

SW4只改变四键用途，不持续屏蔽自动追踪。SW3独立使能自动跟随；按住方向键时临时接管，松开后等待新定位结果继续自动。点颜色由SW3与追踪状态决定，灰=关闭，橙=开启等待，绿=跟踪；不由SW4决定。竖直范围按用户确认的机械结构更新为900..2150us，中位1500us。位置图仅边框和中心十字，以中位为界分别映射两段可达行程。
