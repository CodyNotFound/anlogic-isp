# v41 彩色赛璐璐模式

按用户选择增加彩色赛璐璐渲染，生产模式09 TOON替换原复古效果。正常按K1/K2选模式；SW4手动云台优先，切模式前关闭SW4。其他按钮与云台映射沿用v40。

## 图像算法

1. 两行同步RGB+近似亮度缓冲建立3×3窗口。
2. Scharr亮度梯度与水平/竖直RGB色差共同判断轮廓。亮度接近的不同颜色也能产生轮廓响应。
3. 低梯度区域执行RGB高斯平滑，强边界保留中心颜色，减少跨边界混色。
4. 亮度四舍五入到0、32、64、…、224、255档，把同一亮度偏移加回RGB并限幅，保留色彩差异。
5. 依轮廓强度做半亮、四分之一亮、深色描线，形成色块及墨线。

这是确定性的实时卡通渲染，不涉及模型训练。颜色与轮廓使用相同窗口中心。窗口中心为(max(x-1,0),max(y-1,0))，顶部及左侧复制边界，不读取前帧残留。四级流水接受每时钟一个像素，不添加整帧缓存。

## 接入与时序

pixel_algorithm统一为四个寄存器时钟；原有其他效果增加三个匹配寄存器，数据及所有DE/SOF/EOL/HS/VS同步延迟。AB前的寄存器仍保留，所有模式共享相同延迟，模式切换不会切到不匹配的像素拍。

R2将原有灰度line1/line2改为同步块RAM，通过下一位置地址预取保持上述拍数。24×12及1280×4两种宽度下，共81120个非TOON输出与冻结v40逐像素一致，覆盖有效间隙、帧首、行末和实时切换模式；这项调整不改变TOON的颜色和描线参数。

main RAW ISP参数未在本轮调整。人脸、模板、颜色分析输入仍取自原视频源；分析模块与权重保持v40。显示链路重新验证，不以旧构建时序代替新时序。

## 上板观察

1. SW4关闭，用K1/K2切换到09 TOON；先关闭SW1（AB）观察本版色阶，再按需开启AB比较。确认标题及底栏按键提示正常，切回00检查画幅及同步。
2. 观察真人脸、手办、衣服与桌面，先看大色块和物体轮廓是否符合预期，再看头发、布纹等细节处的描线密度。
3. 用静止场景观察噪声和曝光变化是否导致色阶跳动；缓慢转动摄像头，观察轮廓闪烁或拖影。固定照片回归没有覆盖这些摄像头体验。
4. 再切到11 FACE、12 TRACK、14 REGION，检查原目标框、K4取样/重选及SW3自动云台；SW4手动h/j/k/l映射保持原样。

描线参数位于rtl/isp/pixel_cartoon.v：INK_TH/INK_DARK_TH/INK_SOLID_TH控制三档墨线，SMOOTH_TH控制平滑选择，SHADE_SHIFT控制亮度分层。改变参数需要重新仿真及构建，本次预览与bit只对应本版固定参数。

## 后续可扩展的效果

- 漫画网点：局部亮度控制点阵密度，叠加现有轮廓，可做成印刷漫画风。
- 铅笔线稿：将局部梯度及细节强度映射到白纸上的灰色笔触，保留强弱线条。
- 对焦辅助：在原彩色画面上标出强轮廓，帮助观察清晰区域。

以上是候选方向，尚未集成。当前只替换09复古，不用许多简单调色凑模式数量。后续实现应尽量复用现有窗口和梯度，仍要检查整机物理容量及路由时序。
