# v60 effects and shared tracker storage

Includes v59 controls: SW1 AWB AUTO/HOLD, SW2 sensor AE AUTO/HOLD, SW3 automatic gimbal motion, SW4 manual HJKL; AB fixed ON, compact OSD always visible, required Anlogic Logo retained. Template tracking retained.

Effects: causal per-channel horizontal three-sample median before the existing RGB/Y edge/cartoon window. Dark edge noise floor applies below luma96; weak half-threshold glow removed. Dark cartoon ink thresholds have +12 allowance. Legacy spatial effects use horizontal median luminance. Emboss has a six-level dead zone. Blur uses a rounded 3x3 box (sum*455/4096), stronger smoothing than the old center-heavy Gaussian. Sharpen uses twice the unsharp residual with a six-level detail dead zone, centered on the actual 3x3 center. Normal mode bypasses these spatial filters. Normal color_tone preserves dark RGB instead of converting to gray/halving chroma. Gamma and bright reference saturation remain.

No additional line BRAM. Horizontal filtering adds causal spatial displacement; color/edge of cartoon share the same displaced window and stream qualifiers remain four clocks. This is not a temporal denoiser and can remove single-pixel details. Box division is an explicitly tested fixed-point approximation. We do not claim camera noise is eliminated.

Synthetic fixed-seed 96x48 tests: dark flat noise edge nonzero proportion 99.283% -> 0.0239%; 2% bright impulses 12.162% -> 0.932%; 24-level brightness step and equal-luma color-step contours retained. These are synthetic-scene fractions, NOT camera accuracy or measured optical noise-reduction rates. Constant black/white and all random RGB fixtures checked. 36864 cartoon/edge pixels exact; spatial-mode exact tests and actual shared-suite regression also run independently.

Tracker storage: frame, packed 18-bit scores, and packed nine 9-bit template gradients use idle CNN feature RAM only in mutually exclusive TRACK mode. COLOR queue shares the same arena in REGION mode. FACE reloads its full input before inference.
