# 参赛冻结前核对与演示顺序

## 当前证据

- v72整机STA通过，Slice20855/21216、BRAM108/108、DSP39/40，setup+0.005ns/hold+0.020ns，TNS均0。已将bit、128个源输入和报告归档releases/vision_controls_v72_r1；SHA以该目录completion.json为准。它是可回退的时序合格基准，上板效果仍需实物核对。
- v73是资源/计算等待优化候选，不能在整机STA完成前冒充可用bit。色彩流水150244个像素、65536组通道运算等价；CNN55层659460个激活字节等价；OSD4608000个RGB像素与v72完全一致。
- 720p60指HDMI视频。人脸任务独立运行，单次CNN计算约238ms（候选75MHz下），不是60FPS人脸识别。检测仅定位人脸，不识别身份。
- 普通模式右上角是本工程应用链SOF延迟；分析模式是任务计算耗时。都不包含相机曝光、传感器侧ISP与上游DDR等待，不作为全系统端到端延迟宣传。

## 演示准备

1. 固定光照与机位，00色彩还原：先让白平衡稳定，再锁定；确认红/绿/蓝实物颜色。避免调试过程中转向整面彩色背景改变AWB。
2. 展示07边缘、09卡通、08浮雕及05彩色锐化/06彩色模糊，保持同一有纹理场景，便于对比差异。
3. 11人脸：先关闭SW3固定机位测试框线，避免云台运动混入显示比较；再开启SW3展示视觉联动。SW4只切换方向键用途，按键时临时接管，松开等待新定位恢复自动。
4. 13色区与12模板：先关闭自动运动，把目标放在画面中心按K4选取；选有颜色/纹理、不过曝的目标，再开SW3。切换目标时重新选取。丢失保持位置，不自动归中。
5. 14运动：固定机位、停止云台，等待背景建立后再移动物体。
6. 串口屏需要v72连续编号协议（13色区/14运动）。展示外部控制、实体按键接管及状态回传；不要把“控制权保持”介绍成可检测物理插拔。

## 最后验收

上板后使用同一相机、光照、SW配置对比v63与候选；分别录制SW3关闭和开启的人脸场景，确认框线差异究竟来自定位数据还是云台反馈。测试长期视频稳定、模式切换、过曝暗光、目标丢失、手动接管及串口方向停止。报告只写已经验证的结果；不能用仿真或生成bit替代最终STA和实物证据。
