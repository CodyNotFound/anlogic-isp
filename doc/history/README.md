# 功能与优化历史迁入

2026-10-27 将 colorshading 后续功能按研发顺序迁入本仓库，原有 main 历史保持不变。迁入前起点为 `667bfb605beda783e2fc0017e7932c1f0d601b11`。

迁入内容覆盖色区与显示修复、定点 CNN、地址与缓存优化、模板和色区共享存储、定点量化简化、白平衡和曝光锁定、云台平滑、图像特效、运动检测、模板重捕、中文显示和串口交互。采用功能快照生成逐步提交，作者沿用原仓库配置，提交消息采用中文 `feat/fix/perf/test` 风格，提交日期为实际迁入时间。

`迁入记录.json` 保存原始 source commit 与目标提交对应关系；各提交正文也保存 Source-Commit。归档提交和重复元数据没有伪装成新的功能提交，二进制构建产物不导入。

主线最终 128 个 FPGA 构建输入与原时序通过归档全部逐字节一致。原资源和时序结果来自原构建，本次迁移不把所有历史中间快照标成在目标目录重新编译通过。移植构建脚本后，后续候选在本仓库独立构建并记录结果。

最新 CNN 预取和 OSD 优化候选在原目录有计算等价证据，但整机路由时序未通过；因此后续以独立候选分支验证，达到功能、容量与最终时序要求后才合入稳定主线。
