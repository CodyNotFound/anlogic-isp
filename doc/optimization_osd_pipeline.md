# CNN预取与OSD坐标流水优化

本候选以稳定主线为基准，继续保留逐值等价的色彩算术、16字符可见选择和CNN计算预取，针对原候选的OSD时序瓶颈增加独立坐标映射寄存器。

## 来源与问题

原优化来源为colorshading提交dabb91e。色彩处理以专用移位算术替代通用乘法，可见字符选择从24槽缩为实际需要的16槽；CNN在接受当前MAC数据后预取下一组权重和特征，避免跨通道边界读取。原候选的完整CNN结果与参考一致，核心周期从19992365降低至17828660。

原整机最终setup WNS为-2.362ns。最差路径从HDMI面板的pv_f快照寄存器出发，到r1_compact_color颜色寄存器结束，含约20级逻辑：脉宽到位置换算和像素区域/颜色选择处于同一时钟周期。

## 改动

将水平及竖直PWM到位置图坐标的换算结果分别保存为8位widget_x、widget_y，逐像素组合逻辑只读取这两个寄存器进行位置比较。坐标按现有公式计算，不改变中心、限位或色彩规则。

ph_f/pv_f在帧首更新，位置图位于画面右下角，新映射在扫描到该区域之前已经稳定，因此不增加视频流水级，也不改变显示有效、帧首或行尾的延迟。复位坐标保持中心72/56。异常帧首时序及整机显示仍需对应场景验证。

## 复现

```powershell
./scripts/run_optimized_checks.ps1
./scripts/run_td_verified.ps1 -RunName colorshading_runs_20261027_v74_widget_new -DisableFsmInference -AllowSlicePackingProbe
```

测试包含色彩算术与反压等价、五帧720p实际字库与Logo画面、每轴4096种输入映射、完整CNN逐算子输出，以及UART到PWM控制链。完整网络参考和OSD参考保存在sim目录，避免依赖原工作目录中的报告。OSD完整像素测试使用osd_rom_full_models.v；原osd_rom_sim_models.v将Logo输出固定为零，只适合不检查Logo的控制测试。

生成的日志、图像和工具数据库保存在reports与隔离TD run，不加入源码历史。功能等价、最终容量、建立/保持时序和实板效果分别判断；候选只有达到要求后才进入稳定主线。

## 本轮功能验证

- 色彩算术：65536组通道输入与150244个流式像素逐值一致，含帧控制和反压。
- 完整CNN：55个操作、659460个激活字节逐值一致，17828660个计算周期。
- OSD：真实同步字库与Logo模型下，5帧共4608000个RGB像素与保留参考全部一致。
- 位置图：水平、竖直各4096种输入，包含钳位边界，保持原映射公式。
- 串口：4253字节输入、15组原子状态回传，覆盖控制权保持、查询、本地接管及方向超时。
- 应用：十五模式、普通模式耗时格式，以及UART到真实PWM四方向、人工接管与自动恢复均通过。

以上仿真日志均为0错误、0警告。按75MHz折算，CNN核心约237.72ms，相比基准266.56ms减少约28.85ms、10.82%。完整图像获取与等待新帧的时间另计。最终资源与路由时序以本轮完成记录为准。
