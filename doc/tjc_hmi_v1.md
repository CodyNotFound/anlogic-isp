# 串口屏交接合同 v1（TJC4827X343_011）

本文件是屏幕工程与 FPGA 的固定接口。屏幕负责页面、中文、图标和按钮；FPGA 负责视频算法、实际状态与舵机限位。现有 HDMI OSD 保持独立，不因串口屏而删减。本文接口为项目自定义，不是淘晶驰原生回包协议。当前版本的 RTL 正在集成/验证；不代表已经接线验证。

## 先做的界面

1. 主页面 main：模式名称、等待/跟踪中/搜索中/目标丢失/手动控制/追踪关闭状态；目标 X/Y、水平/竖直脉宽、FPS、算法耗时 ms。未找到目标时 X/Y 显示 --，耗时无效时显示 --。耗时不是采集到显示的总延迟。
2. 模式选择：0色彩还原、1灰度、2反色、3二值、4增亮、5锐化、6模糊、7边缘、8浮雕、9卡通、10换色、11人脸、12模板、14色区、15运动。13已退役，禁止发送。可拆成“取景/跟随”和“图像效果”两页，页面名称/美术自由，但变量必须在 main 页且设为全局。
3. 四个开关：手动、追踪、自动曝光、白平衡。曝光/白平衡分别是 自动/锁定，锁定保持已调参数，不是绕过 ISP。追踪开关只控制自动云台动作，检测仍运行。AB 固定开启，不加 AB 开关。
4. 手动页：左/下/上/右大按钮。按下发送方向，保持时每50ms重发，松开发停止；离开页面/触摸取消也必须发停止。切换到手动后再允许方向按钮。物理手动开关开启时，屏幕不能解除手动。
5. “重新选取”按钮：仅模板12和色区14可用，目标应放在画面中心；运动15对应“重建背景”。人脸11自动检测，不提供身份识别或点选人脸功能。
6. 连接状态：超过1秒没有新的完整状态包则显示“连接中断”，停止方向重发，禁止继续显示为已执行。屏幕启动只请求状态，不自动发送初始开关值覆盖 FPGA。

第一版不做视频预览、图像传输、舵机绝对位置滑条、自动回中、方向翻转、未知参数调节。后续可扩展；先保证按钮与物理开关一致。

## 串口

115200，8数据位，无校验，1停止位；全双工。FPGA 暂预留 J1-3（E12）为 RX、J1-4（E16）为 TX，均为3.3V逻辑。屏幕电源、TX输出电压及是否需要电平转换仍需按完整型号硬件资料核对，当前不要按本文猜接线。

### 屏幕 -> FPGA（6个原始字节，无 FF 尾）

A5 5A OP ARG CHECK 0D
CHECK = FF XOR OP XOR ARG

使用 printh 发送固定十六进制常量；不要额外勾选发送组件ID/坐标或发送键值。错误校验、未知OP、无效参数被丢弃；帧中断超时重新同步。

| OP(hex) | ARG | 含义 |
|---|---|---|
|01|00|请求当前状态（可在页面启动时发）|
|10|模式编号|选择上述模式，禁止13|
|11|00/01|白平衡锁定/自动|
|12|00/01|曝光锁定/自动|
|13|00/01|追踪关/开|
|14|00/01|请求退出/进入手动；物理手动开关具有优先权|
|15|00|重新选取/重建背景；按当前模式解释|
|16|方向掩码|左08、下04、上02、右01，停止00；相反方向同时按不产生该轴运动|

方向是短租约命令：FPGA 在250ms没有收到新的方向命令时强制停止屏幕方向输入。屏幕断电/断线不会保持运动。物理按键方向优先于屏幕方向。自动跟随和手动指令沿用硬件限位；不开放任意脉宽写入。

例：开启追踪：printh A5 5A 13 01 ED 0D
例：停止：printh A5 5A 16 00 E9 0D
例：向左按住：printh A5 5A 16 08 E1 0D

完整按钮事件常量见同目录 tjc_hmi_v1_events.txt。

### FPGA -> 屏幕（淘晶驰原生 ASCII 赋值）

在 main 页创建13个数值变量控件，名字 vA..vM，vscope设为全局。必须保持名字不变，显示控件、按钮名称可以自由设计。

|变量|数值|用途|
|---|---|---|
|vA|0..15（无13）|实际模式|
|vB|0..15|功能位：bit0白平衡自动，bit1自动曝光，bit2追踪开启，bit3实际手动|
|vC|0..7|0等待、1跟踪中、2搜索中、3目标丢失、4手动控制、5追踪关闭、6取样中、7取样失败|
|vD|0..1279|目标X；vI=0时不显示旧值|
|vE|0..719|目标Y；vI=0时不显示旧值|
|vF|500..2500|水平命令脉宽，单位us|
|vG|1050..2150|竖直命令脉宽，单位us|
|vH|0..9999|算法耗时ms；vJ=0时无效|
|vI|0/1|目标坐标有效|
|vJ|0/1|算法耗时有效|
|vK|0..99|视频FPS，与人脸检测更新率不同|
|vL|0/1|物理手动开关开启；为1时禁用“退出手动”|
|vM|0..99循环|包提交序号，最后更新|

FPGA 大约每100ms依次发送 vA..vL，然后发送 vM；同一包来自同一快照。查询由下一个周期状态包应答（最长约100ms），不会插队缩短包间隔，因此每包后留有超过20ms的显示刷新窗口。屏幕启动查询一次即可，不要循环查询。每条赋值使用原生ASCII，末尾为三个FF：
main.vA.val=0011 FF FF FF
main.vH.val=0267 FF FF FF
main.vM.val=0001 FF FF FF

上面 FF 是字节 FF，不是字符串。屏幕定时器只在 vM 改变时把 vA..vL拷贝到显示控件，避免一半新一半旧。建议20ms检查一次序号。启动时将 vM 和本地“上次序号”均设为65535，收到0..99中的新序号才显示为已连接；之后处理99→0回绕。数值变量均可接收4位十进制赋值。界面不要把本地按钮值当作真实状态，开关颜色/状态最终以 vB 回报为准。模式15的状态1显示为“运动检测”，不表示云台会追踪运动区域。

mode名、状态名、图标、中文说明全部由屏幕本地映射。FPGA 不发送中文字串或位图，减少逻辑和串口带宽。13条约247字节/包，10Hz约2.47KB/s，低于115200 8N1的有效字节速率。

## 物理控制规则

物理 SW/按键动作优先；稳定开关电平不会每拍覆盖触屏设置。开机先读取物理开关，之后同一项由最新有效操作更新。物理手动开关保持安全优先，开启时始终是手动。模式实体按键与屏幕模式选择共用同一个模式状态；不维护两套模式。

- 演示停止/断链时的行为；页面切换必须停方向。
