# v55 模型专用、逐值等价的卷积量化电路

在 v53 的共享颜色队列基础上，CNN 不再实例化通用的 64 位双向移位量化路径。模型的全部 1524 个输出通道移位均为正数，使用 33 位有符号扩展、加舍入项、算术右移及原本的 int8 饱和/ReLU 即可逐值等价实现。33 位可容纳任意 int32 累加值和移位 1–31 的舍入项，不依赖开发照片观察到的较小累加峰值。

`yunet_dot4` 的通用实现和默认参数仍保留；仅 `yunet_network` 实例显式选择 `MODEL_SHIFT=1`。导出脚本及发布校验检查正移位合同，防止更换模型后默默截断不支持的移位。没有改变网络、权重、输入尺寸、置信度阈值、计算周期和饱和规则。

## 证据

旁路试验已验证 262136 组 int32 极值、二的幂边界、固定种子随机数、移位 1–31 及两种 ReLU 设置，全部与原通用 int64 算法一致。独立完整核心最终为 3217 slices、52 RAM、4 DSP，75MHz 路由 setup +0.713ns、hold +0.022ns、TNS 均为零。相对 v52 路由核心实际减少 403 slices。

完整网络逐算子回归已通过，55 算子、659460 字节全部相同，仍为 19992365 个计算时钟。日志来自已冻结的旁路候选；`reports/yunet_v55/shift_contract.json` 核对两份候选 RTL 与本轮实际编译 RTL 字节完全相同，所有权重和指令文件保持不变。1524 个实际移位范围为 4–23。

原生 RGB→PWM 回归也已通过，921600 RGB 像素实际进入采样、完整 CNN、坐标解码和云台控制，得到中心 (936,404)、水平 1485us、竖直 1500us，并验证无后续结果时保持位置，编译/仿真均 0 错误、0 警告。`rom_load_check.json` 核对 TD Check 实际读取全部 10 个 CNN ROM，且确实例化 MODEL_SHIFT=1。

实际整板构建 `colorshading_runs_20261025_v55_cnn_shift_r1` 已进入布局布线；最终结果待日志及 job/completion JSON，尚不能据此称可上板。模板/颜色共享与原有任务链功能证据继承 v53：本轮仅改变 FACE 中使用的卷积量化函数，不改变共享存储读写路径。v53 对照及回归日志一并保存。

全图特征字打包试验 v54 尽管全部 55 算子逐字节一致，却没有节省 RAM，未合入本轮。继续保留 v53 背景编译及每轮失败证据。

本轮仍是单脸定位，非身份识别。CNN 约每 267ms 计算一次，不是 60FPS 人脸检测；尚无实际摄像头、显示或机械闭环验收，未烧录。SW3 OSD、安路 Logo、手动优先及目标丢失不归位均保持原合同。
