# v68 整体 OSD 可读性修正

用户要求：英文数字用先前较粗点阵；放大主OSD文字，不继续扩大已经很大的云台位置显示。

- 42个ASCII字形逐值恢复v66 Aurora点阵；86个中文字形保持v67 ZLabs原始点阵。128字、2048×16字库容量不增加。
- 模式、状态、坐标、FPS、PROC与底栏均使用整数2倍像素寻址，中文32×32；英文墨迹20×28，字格32×32。不使用1.5倍重采样，不对字模额外描边。
- 顶部左侧模式(196,26)、状态(196,70)、坐标(196,114)。右上FPS(900,26)、PROC(900,70)。右上预留352px完整耗时文字，不裁切。
- 底栏保持两行，736×76，不做全宽大面板；手动/追踪/自动曝光/白平衡分配144/144/240/208像素列宽，第二行仍为按键功能。
- 云台框保持192×176、原网格和指令点大小，文字仍16px字格。整体上移44px避免与底栏重叠；安路Logo位置、大小、调色板及透明索引不变。
- v67彩色锐化/模糊、云台短程响应、跟踪、串口屏、AE/AWB/AB均不在本轮更改范围。v67时序合格bit与128个输入已校验归档到releases/vision_color_font_v67_r1。

实际RTL预览和逐像素校验结果见reports/osd_v68；新整机需独立综合、布局布线后才可作为上板候选。
