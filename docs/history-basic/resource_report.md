## 优化建议

1. UDP栈条件编译移除 → 省约23% LUT
2. Logo ROM游程压缩(640KB→80KB) → 省14 BRAM
3. 算法模式门控(已实现) → 动态功耗约-60%翻转率
4. SD驱动可选编译
5. 4路mux改one-hot
